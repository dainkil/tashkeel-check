## 새 ADR 작성 템플릿

한 결정 한 파일(`docs/adr/ADR-NNN.md`). 기존 ADR을 뒤집으면 새 ADR을 추가하고 서로 연결한다.

```markdown
# ADR-XXX — 결정 제목
- 날짜:
- 상태: 제안 / 채택 / 보류 / 폐기 / 다른 ADR로 대체
- 배경과 문제:
- 검토한 대안:
- 결정:
- 선택 이유와 근거:
- 비용·성능·구조에 미치는 영향:
- 재검토 조건:
- 관련 코드·실험·트러블슈팅:
- 대체하거나 대체된 ADR:
```
