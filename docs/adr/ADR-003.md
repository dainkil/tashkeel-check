# ADR-003 — 단계 1의 도구는 형태소 분석기 하나로 하고, RAG·벡터 DB·이름 사전은 실제 서류 묶음이 들어오면 붙인다

- 날짜: 2026-10-13
- 상태: 채택. 같은 날 ADR-007로 보완(묶음 검색의 틀은 먼저 만들되 단계 1 조건에는 붙이지 않음)
- 배경: 묶음 내 서류 검색은 같은 사람이 여러 서류에 나오는 묶음이 있어야 시험할 수 있는데, 공개 자료로는 구하기 어렵다.
- 결정: 단계 1은 CAMeL 분석기만 쓰고, 벡터 DB·임베딩·텍스트 분할·이름 사전은 단계 2로 미룬다.
- 결정 이유: 합성 묶음에서는 검색이 근거를 찾는지가 생성기 설계에 달려 측정 의미가 약하다. 기능을 줄이면 측정에 집중할 수 있다.
- 고려한 대안: 합성 참고 자료 묶음으로 검색 툴까지 구현.
- 최종 결정: 단계 1의 고유명사 근거는 같은 문서 안의 라틴 문자 표기뿐이고, 골격의 Qdrant 부분은 쓰지 않는다. 재검토: 실제 서류 묶음을 받을 때, 과제 요건상 RAG가 반드시 필요할 때(단계 2 설계를 앞당긴다).
