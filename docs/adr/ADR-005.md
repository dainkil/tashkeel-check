# ADR-005 — CAMeL Tools 기본 DB(GPL v2)는 내부 측정에만 쓴다

- 날짜: 2026-10-13
- 상태: 채택
- 배경: CAMeL Tools 코드는 MIT지만 기본 형태소 DB calima-msa-r13은 GPL v2다([공식 문서](https://camel-tools.readthedocs.io/en/latest/api/morphology/database.html), 사업성 검토 문서).
- 결정: 기본 DB는 단계 1의 연구·측정에만 쓴다.
- 결정 이유: 라이선스가 GPL v2라 배포 형태에 쓰려면 법률 검토가 먼저 필요하다.
- 고려한 대안: 기록 없음.
- 최종 결정: 고객 환경 설치 등 배포 형태로 넘어가기 전에 법률 검토를 하고, README에 적는다. 재검토: 배포형 제품을 설계할 때. ADR-021 이후 분석기는 제품 경로의 필수 부품이 아니어서 검토 범위가 줄었다.
