# ADR-001 — 음성 모음 검수에서 아랍어 문서 검수로 방향을 바꾸고 이전 계획을 삭제한다

- 날짜: 2026-10-13
- 상태: 채택
- 배경: 이전 계획은 TTS 데이터 팀을 위한 음성 근거 기반 모음 검수였다. 사업성 검토에서 구매자를 "아랍어를 못 읽는데 아랍어 문서에 책임을 지는 사람"으로, 언어쌍을 아랍어 → 영어로 다시 정했다.
- 결정: 아랍어 문서 검수로 방향을 바꾸고 이전 계획 본문을 삭제한다.
- 결정 이유: 사용자 요청. 두 계획이 한 문서에 있으면 작업자가 범위를 잘못 읽는다.
- 고려한 대안: 이전 계획을 보류로 남기고 새 계획 추가 / 두 계획 병행. 둘 다 두 계획이 한 문서에 남는다.
- 최종 결정: 계획 문서를 새로 쓰고 이전 ADR은 이어받지 않는다. 이전 데이터(ClArTTS, ArVoice 등)와 모델 조사는 쓰지 않으며, 필요하면 git 기록에서 찾는다.
