# ADR-014 — EXP-002 전에 채점 정의 4건을 고치고 보류 후보 적중률을 더하며, 합성 문서를 근거 배치가 섞인 synthetic-v1로 바꾼다

- 날짜: 2026-10-20
- 상태: 채택
- 배경: M0에서 실제 모델로 synthetic-v0 dev 문서 2개를 돌려 보니([진행 기록](../archive/progress-log.md)), 지표가 모델 행동보다 채점 정의의 버릇을 재는 곳이 네 군데 있었다.
  1. 모호 판정 규칙이 من·على 같은 일반 단어를 많이 잡았다.
  2. 중립 토큰이 다른 지표에서는 빠지는데 미처리에서는 빠지지 않았다.
  3. 과잉 표시가 항목 단위라 항목을 쪼개거나 묶는 방식만으로 값이 바뀌었다.
  4. 이름을 보류하고 그 이름을 덮는 단어 항목을 따로 채택하면 근거 없는 확정으로 셌다.

  또 합성 문서가 모두 "근거 전부" 아니면 "근거 없음"이라, 한 문서 안에서 확정과 보류를 나누는 경우가 없었다. EXP-002는 아직 돌리지 않았다.
- 결정: 모호 판정 규칙은 두고 보고 방식만 고친다. 보류 후보 적중률을 더하고, 합성 문서를 근거 배치가 섞인 synthetic-v1로 바꾼다.
- 결정 이유: 모호 판정 결과는 C2 툴 결과와 C3 프롬프트에 들어가는 LLM 입력이라, 규칙을 바꾸면 실험 조건과 LLM 입력 해시가 바뀐다. 수정 4건과 문서 보강은 C0 결과와 무관하게 필요해서 먼저 했다. 섞인 문서가 필요하다는 근거는 "실제 서류 묶음은 섞여 있다"는 가정이다[가설]. eval로 어떤 모델도 돌리지 않았으므로 평가 데이터로 튜닝한 것이 아니다.
- 고려한 대안: (규칙) 모호 판정 규칙을 좁힘(표제어가 다를 때만, 기능어 제외). (문서) 그대로 둠 / eval만 바꿈. (순서) dev로 C0를 먼저 돌려 본 뒤 정함.
- 최종 결정:
  - 일반 단어 미처리는 보조 지표로 내린다. 중립 토큰은 처분을 기대하지도 감점하지도 않는다. 과잉 표시와 근거 없는 확정은 토큰 단위로 센다(`_tokens` 키). 한 토큰을 여러 항목이 덮으면 고유명사 항목으로 판정한다. 보류 후보 적중률(보류 항목 후보에 `english_used`가 든 비율)을 더한다.
  - synthetic-v1은 근거 줄을 역할마다 붙이고, 문서 유형마다 근거 배치 없음·일부·전부를 같은 수로 나눈다. seed(1001·2002)와 문서 수(10·30)는 그대로다.
  - 영향: 골든을 두 번 다시 만들었고 사용자 메시지 해시만 바뀌었다(프롬프트·스키마·툴 해시는 그대로). eval의 근거 없는 이름이 44개에서 61개로, 그런 이름이 든 문서가 12개에서 20개로 늘었다. EXP-002 규모와 비용은 그대로다.
  - 재검토: 실제 서류의 근거 배치 분포 자료가 생길 때, 정답 표기가 여럿인 실제 문서를 잴 때.
