# ADR-020 — EXP-003 본 실행: 참고 조건 C1p0, 단계적 반복, OpenAI flex 처리 등급

- 날짜: 2026-10-21
- 상태: 채택. 2026-10-21 eval 실행 완료(판정 `stop`)
- 배경: EXP-003의 eval(70개, 이름 부분 1,457개)과 채점이 고정됐다(ADR-017). 일반 호출로 반복 3회를 돌리면 약 $46(참고 조건 포함 약 $55), 동시 4개로 약 4.5시간이다[추정]. 사용자는 참고 조건 C1 + 옛 지시문 p0를 넣고, 반복은 1회를 먼저 돌려 애매할 때만 더 돌리고, 전체를 4시간 안에 끝내기를 원했다.
- 결정: 참고 조건 C1p0(반복 1회), 실행 전에 고정한 단계적 반복, OpenAI flex 처리 등급, 동시 16개로 돌린다.
- 결정 이유: flex는 Batch와 비슷하게 할인되면서도 지금 실행 장치(동시 호출·재개)를 그대로 쓴다. 99%에서 먼 결과는 반복을 더해도 판정이 바뀌지 않으므로 회색 구간에서만 반복을 더한다. 규칙을 미리 코드로 고정해 사람이 결과를 보고 멈추는 선택 편향을 막는다(ADR-016). 참고 조건은 판정에 쓰지 않으므로 1회로 충분하다.
- 고려한 대안: (비용) Batch API(결과가 최대 24시간 뒤라 C2의 툴 왕복과 단계 판단 때문에 4시간을 보장할 수 없음) / 추론 강도 낮추기(모델 조건이 바뀌어 99% 달성을 낮게 잴 수 있음) / 문서·조건 줄이기. (반복) 3회 고정 / 1회. (참고 조건) 모든 반복 / 넣지 않음. (동시 실행) 4 / 8.
- 최종 결정:
  - C1p0는 C1에서 지시문만 p0로 바꾼 조건이다. 반복 1회만 돌리고, 판정에는 쓰지 않으며, "C1 − C1p0"로 보고한다.
  - 단계적 반복: 반복 1회 뒤 C1~C3의 안전·엄격 점추정 6개 가운데 하나라도 [0.98, 0.995) 안이거나 값이 없으면 반복 2·3을 돌고, 아니면 1회로 마친다. 판단은 기록 파일에 `stage` 줄로 남는다.
  - 처리 등급 `--service-tier flex|default`는 plan이 아니라 세션 기록에 남겨 재개 때 바꿀 수 있다. flex dev 점검으로 계산한 동시 16개의 최대 소요가 3.5시간 이하면 flex, 아니면 기본 등급을 쓴다. 속도 제한에 걸리면 동시 8개로 낮춘다.
  - 결과: flex로 반복 1회 350회를 약 21분·약 $10에 마쳤고 판정은 `stop`이다([EXP-003](../experiments/EXP-003.md)).
  - 재검토: flex가 자주 막혀 기본 등급으로 바꿀 때, 4시간 안에 끝나지 않을 것으로 보일 때.
