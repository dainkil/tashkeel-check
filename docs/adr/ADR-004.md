# ADR-004 — 분석기는 항상 실행하고, 처분 확인과 지표는 코드가 한다

- 날짜: 2026-10-13
- 상태: 채택
- 배경: 측정하려는 실패가 "LLM이 모호한 곳을 말없이 넘기는 것"이다.
- 결정: analyze 노드는 모든 조건에서 돌고, 처분 누락 확인과 지표 계산은 코드가 한다.
- 결정 이유: 탐지나 누락 확인을 LLM에 맡기면 같은 실패가 측정 단계에서 반복된다.
- 고려한 대안: 분석기를 툴로만 제공(LLM이 부르지 않으면 분석이 없어 조건 비교가 흔들린다) / LLM이 자기 처분을 요약(누락 확인을 LLM에 맡기게 된다).
- 최종 결정: LLM은 토큰 ID로 대상을 지목하고, reconcile이 강등 규칙과 지표를 코드로 계산한다([4.5절](../archive/document-review/architecture.md)). 결과는 LLM 호출 여부와 무관하게 비교할 수 있고, LLM의 확신도는 판정에 쓰지 않는다.
