# ADR-006 — 골격의 LangChain·LangGraph·LangSmith 방식을 따르고, 모델은 OpenAI를 설정값으로 둔다

- 날짜: 2026-10-13
- 상태: 채택
- 배경: 코드 골격(`~/Documents/skala_langgraph`)이 `init_chat_model`, `create_agent`, `StateGraph`, `@traceable`, `.env` 형식을 쓴다. 노트북마다 모델 제공사가 다르다(Gemini, OpenAI).
- 결정: 골격의 방식을 그대로 쓰고, 모델은 OpenAI를 설정값으로 둔다.
- 결정 이유: 사용자가 OpenAI를 쓰기로 정했다. 기본 모델 `gpt-6.1-sol`은 OpenAI 모델 문서가 균형형으로 소개하는 모델이다([문헌○](https://developers.openai.com/api/docs/models), 2026-10-13 조회).
- 고려한 대안: 노트북에 있던 다른 제공사(Gemini). 사용자 결정으로 고르지 않았다.
- 최종 결정: 기본 모델은 `openai:gpt-6.1-sol`이고 `.env`의 `MODEL`로 바꾼다. 한 실험 안에서는 모든 조건에 같은 모델을 쓰고 모델 ID를 실행마다 기록한다. 구조화 출력은 `ToolStrategy`로 고정한다. `temperature`는 보내지 않는다(이후 M0에서 0이 거부됨을 확인). 실제 실행에는 `OPENAI_API_KEY`가 필요하고, 없으면 가짜 모델로만 돈다. 재검토: 구조화 출력이나 tool call이 안정적으로 나오지 않을 때.
