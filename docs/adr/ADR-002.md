# ADR-002 — 단일 에이전트를 기능은 적고 측정은 많은 실험 장치로 만들고, 조건 C0~C3로 비교한다

- 날짜: 2026-10-13
- 상태: 채택
- 배경: Q1~Q3([1.3절](../archive/document-review/problem-and-goals.md))에 답해야 하고, 단계 3의 멀티 에이전트 비교에 쓸 베이스라인이 필요하다.
- 결정: 같은 그래프에서 LLM에게 보여 주는 것만 바꾸는 조건 C0~C3를 두고 비교한다.
- 결정 이유: 조건이 설정값이라 기능을 늘리지 않고 질문마다 비교 대상을 만들 수 있다. 한 번에 한 요소만 바꾼다.
- 고려한 대안: 제품 시제품부터 구현 / 탐지 노드를 강제하는 단일 구성만 구현.
- 최종 결정: 조건은 [4.4절](../archive/document-review/architecture.md)에 정의한다. 분석기·검증·집계는 모든 조건에서 같은 코드로 돈다. 조건 × 문서 × 반복만큼 LLM 비용이 든다. 재검토: C2와 C3의 차이가 반복 간 범위 안이면 단계 2부터 하나로 줄인다.
