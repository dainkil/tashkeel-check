# ADR-007 — 서류 묶음 검색(RAG·벡터 DB)은 틀만 먼저 만들고 꺼 둔다

- 날짜: 2026-10-13
- 상태: 채택(ADR-003 보완). 저장 방식은 ADR-011, 역할(근거 출처 → 후보 힌트)은 ADR-018이 바꿈
- 배경: 사용자가 RAG와 벡터 DB의 틀을 먼저 만들어 두기를 원했다. 단계 1 조건에 붙이면 C0~C3 비교가 흔들린다(ADR-003).
- 결정: `rag/bundle.py`에 묶음 검색을 만들되 기본은 꺼 둔다.
- 결정 이유: 틀이 있으면 묶음이 생길 때 바로 붙일 수 있고, 꺼 두면 단계 1 비교가 그대로다.
- 고려한 대안: 단계 2까지 아무것도 만들지 않음(ADR-003 원안) / 만들어서 단계 1 조건에 바로 붙임(C0~C3 비교가 흔들림).
- 최종 결정: 아랍어 철자 정확 일치(이중 언어 줄의 라틴 표기 회수), 로마자 유사 일치(`match_spelling`), Qdrant 메모리 벡터 검색(Child로 찾고 Parent를 돌려줌)을 합치고 결과마다 출처를 붙인다. 임베딩은 키가 있으면 `text-embedding-3-small`, 없으면 연습용 문자 n-gram이다. `ENABLE_BUNDLE_SEARCH=true`와 `--bundle`을 함께 줄 때만 `search_bundle` 툴이 붙고, `exp002`는 쓰지 않는다. 검색 품질은 재지 않았다. 재검토: 실제 서류 묶음을 받을 때.
