# ADR-010 — 이름 사전 적중은 고객 단위로 자동 확정하고, 등록은 사람이 보류 항목을 닫을 때만 한다

- 날짜: 2026-10-20
- 상태: 채택. 사전 키는 ADR-018(대상 ID 추가)과 ADR-021(문서 경로의 고객 전체 키 `*`)이 보완
- 배경: 사용자가 "애매한 고유명사를 두 번 안 찾아도 되게 저장하는 기능이 있는가"를 물었다. 이름 사전(F9)은 단계 2 기능으로만 적혀 있었고, 적중을 근거로 볼지, 누구의 사전을 볼지가 정해지지 않았다.
- 결정: 사전 적중은 같은 고객 안에서 자동 확정하고, 사전 등록은 사람이 보류 항목을 닫을 때만 한다.
- 결정 이유: KYC 담당자는 같은 실소유자의 서류를 반복해서 받는다[가설]. 이미 확정한 표기를 다시 보류하면 도구의 가치가 없다. 사람이 외부 근거로 닫은 표기는 "표기는 외부 근거로 확정된다"는 원칙과 맞아 근거로 쓸 수 있다.
- 고려한 대안: 참고만(사전 표기를 후보 맨 앞에 두되 매번 닫음) / 전역 사전(같은 철자가 다른 사람일 때 다른 고객의 표기를 근거로 쓰게 됨) / 근거 채택 결과 자동 등록(에이전트 오류가 사전에 굳어 이후 묶음으로 번짐).
- 최종 결정: 키는 정규화 아랍어 전체 이름 + 고객 ID다. 적중하면 근거 출처 `glossary`로 확정하고 `glossary_hit`를 표시한다. 다른 고객의 사전은 보지 않는다. 확정 순서는 같은 문서 → 같은 묶음 → 고객 사전 → 보류다. 같은 고객 안의 동명이인은 막지 못한다. 재검토: 사전 적중의 오확정이 관찰될 때, 고객이 사전 적중도 매번 확인하기를 요구할 때.
