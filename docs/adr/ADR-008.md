# ADR-008 — 사업 구조를 걸프 영어권 최종 사용자·사람 검수 없음으로 바꾸고, 인터뷰와 사람 검수는 추후 과제로 둔다

- 날짜: 2026-10-20
- 상태: 채택
- 배경: 수요·공급 조사에서 한국 쪽 고객 모수가 작았다(닿을 수 있는 7~25곳, 손익분기 270곳). 한국 쪽 자료는 언어를 애로로 꼽지 않았고, 아랍어 검수자 시급이 장당 손익의 부호를 정한다는 위험이 드러났다. 사용자는 한국어일 이유가 없고, 번역사무소는 대체 대상이라 고객이 될 수 없으며, 인터뷰와 사람 검수는 할 수 없다고 정했다.
- 결정: 고객을 걸프(사우디·UAE) 영어권 최종 사용자로 바꾸고, 제품에 사람 검수를 넣지 않는다. 인터뷰와 사람 검수는 추후 과제로 둔다.
- 결정 이유: 이름 표기는 아랍어 실력이 아니라 외부 근거로 확정되므로([1.1절](../archive/document-review/problem-and-goals.md)) 사람 검수 없이도 핵심 주장이 성립한다. 사람 검수를 빼면 장당 원가가 API 비용뿐이라, 걸프 가중 가격 기준 손익분기가 105곳(급여) / 13곳(대학생 팀)으로 내려간다(`docs/archive/business/market/recalc_gulf.py`). 번역사무소에 팔면 대체하려는 대상에게 파는 셈이다.
- 고려한 대안: 한국 고객 유지(수출바우처·한국어 출력) / 번역사무소·법률 AI·이름 매칭 업체에 부품 공급 / 사람 검수를 포함한 걸프 최종 사용자 판매.
- 최종 결정:
  - 언어쌍은 아랍어 → 영어 그대로다. 보류된 이름은 고객이 신분증·영문 등기 같은 외부 근거로 확정하고, 이름 외 보류 구간은 고객이 판단한다. 사업 판단은 공개 자료 추정과 자동 측정(EXP-001·002, 공개 이중언어 문서)으로 한다.
  - 영향: 단계 2에서 사람 검토(interrupt)가 빠지고 API·업로드 화면과 공개 문서 측정이 들어온다. 결과는 "합성 문서·공개 문서 기준"으로만 보고한다. 보증은 "전수 검토를 건너뛰어도 된다"에서 "어디를 확인해야 하는지 알려 준다"로 약해진다. 이전 구조의 사업 작업(바우처, 한국어 출력, 검수자 단가)은 범위에서 빠진다.
  - 재검토: 지시만으로 충분하다는 결과가 나올 때, 인터뷰나 아랍어 검수자를 쓸 수 있게 될 때, 공개 이중언어 문서를 구할 수 없을 때.
  - ADR-001의 고객 정의(아랍어를 못 읽는데 책임을 지는 사람)는 그대로 두고 지역과 판매 형태를 좁힌다.
