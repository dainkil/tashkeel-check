## 해석할 때 주의

- **데이터:** 이름 벤치는 공개 인물(Wikidata·Wikipedia) 위주다. 고객 이름 분포로 일반화하지 않는다.
- **라벨러:** 자체 라벨은 아랍어 원어민 2인이 필요하다. 구하지 못하면 CamelProp만 쓰고 걸프 방언 독법은 재지 않는다.
- **청취 평가:** 주 지표는 사람 청취 객관식이다. ASR 왕복·강제 정렬은 선별·보조다. MOS는 쓰지 않는다.
- **엔진 변동:** 엔진은 모델·지원 범위를 바꾼다. 매트릭스에는 실험 날짜를 적는다.
- **설계자:** 이름 세트 선별·평가표·판정 기준을 같은 작업자(Claude)가 설계한다. 라벨과 청취는 사람이 한다.
