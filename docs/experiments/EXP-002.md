# EXP-002 — 조건 C0~C3 비교 (Q1~Q3)

- 상태: **계획됨, 미실행** (2026-10-13 사용자 지시로 실험은 돌리지 않음)
- 확인할 질문: Q1 에이전트가 말없이 찍는가(C0), Q2 지시만으로 해결되는가(C1 대 C0), Q3 분석기를 주면 더 잡는가(C2·C3 대 C1)
- 데이터: 합성 평가 문서 `data/synthetic/eval/` 30개(seed 2002). 개발 문서 10개(seed 1001)는 프롬프트 디버깅에만 쓴다
- 규모(사용자 확정): 조건 4 × 평가 문서 30 × 반복 3 = 360회
- 모델: `openai:gpt-6.1-sol`(`.env`의 `MODEL`), 모든 조건에 같은 모델

## 실행 전에 고정한 것 (2026-10-13)

- 정답 기준: 고유명사가 나올 때마다, 문서 안에 영문 표기가 있으면 기대 처분은 근거 채택(인용), 없으면 보류
- 주 지표: 근거 없는 고유명사 토큰 가운데 표시도 보류도 없이 하나로 옮긴 비율(말없이 찍음)
- 보조 지표: 근거 없는 확정, 보류율, 근거 채택 검증 통과율, 근거 검증 실패, 미처리, 과잉 표시, 고확신 무근거 확정(**확신도 ≥ 0.8**, 사용자 확정), 표기 불일치, 도구 사용, 비용, 반복 간 범위
- C0 판정 규칙 v0(`reconcile._marked`). 실행 후 자동 판정 20건을 사람이 확인한다
- 비율은 문서별 평균이 아니라 개수를 합쳐 계산한다. 반복 간 범위와 문서 단위 부트스트랩 95% 구간을 같이 낸다
